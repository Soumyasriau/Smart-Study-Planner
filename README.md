# 📘 Smart Study Planner

A simple web app to plan your study goals and track tasks on a timeline.

🚀 **[Live Demo](https://studysmartplanner.pages.dev/)**

## Features
- Add study tasks
- View your study goals in one place
- See your tasks on a timeline
- Lightweight, runs in the browser with no installation

## Tech stack
- HTML
- CSS
- JavaScript
- Hosted on Cloudflare Pages

## Run locally
```bash
git clone https://github.com/Soumyasriau/Smart-Study-Planner.git
cd Smart-Study-Planner
```
Then open `index.html` in your browser.
